# MiroFish Ops — симуляция аудитории на сервере + Telegram-запуск

Обвязка вокруг форка [`amadad/mirofish`](https://github.com/amadad/mirofish): движок
мульти-агентной симуляции, который прогоняет текст (оффер, прайс, лендинг, пост) через
синтетическую аудиторию и отдаёт разбор — какие возражения всплывут, где рушится доверие,
какие обещания не проходят проверку математикой.

Сам движок — чужой AGPL-код, он в репо не живёт (клонируется на сервер). Здесь только
наше: установка, изоляция, лимиты и интерфейс.

## Что это даёт

Василий кидает боту текст с телефона — получает разбор реакции аудитории **до** того,
как на этот текст потратили рекламный бюджет. Расход API — ноль: движок считает через
`claude` CLI, то есть через подписку.

Трезвая оговорка: симуляция хорошо ловит **спектр возражений и тон** и плохо предсказывает
**конверсию в цифрах**. Генератор гипотез, не замена A/B-тесту.

## Где и как это живёт

| что | где |
|---|---|
| площадка | VPS 4 ГБ; рядом может жить боевой сайт — отсюда жёсткие лимиты |
| пользователь | системный `mirofish`, домашний каталог `/opt/mirofish` |
| движок | `/opt/mirofish/app` (форк, venv на Python 3.12 через uv) |
| бот | `/opt/mirofish/bot.py`, сервис `mirofish-bot` |
| конфиг | `/opt/mirofish/.env` (токен бота, белый список id), права 600 |
| отчёты | `/opt/mirofish/app/uploads/runs/<run_id>/report/` |
| лог | `/var/log/mirofish-bot.log` |

## Состав

- **`install-mirofish.sh`** — установка движка: пользователь, свой Node и Python
  (системные не трогаем), uv, клон форка, `claude` CLI + шим `claude-cli`.
  Идемпотентен, начинается с гейта по свободному диску.
- **`bot.py`** — Telegram-бот без единой внешней зависимости (stdlib, long-polling,
  наружу ничего не слушает). Белый список по числовым id, очередь на одну симуляцию
  за раз, выжимка из `verdict.json` + `report.md` файлом.
- **`mirofish-bot.service`** — юнит с `MemoryMax=1200M`, `CPUQuota=200%`,
  `RestartSec=30`, `StartLimitBurst=5` и полной изоляцией ФС.
- **`deploy-bot.sh`** — выкат бота, конфига, logrotate и юнита.

## Порядок установки

```bash
# 1. движок (один раз)
bash install-mirofish.sh

# 2. авторизация подписки — интерактивно, нужен Василий
sudo -u mirofish -H bash -lc 'claude'       # пройти вход, вставить код

# 3. проверка
sudo -u mirofish -H bash -lc 'cd /opt/mirofish/app && .venv/bin/mirofish doctor'

# 4. бот
bash deploy-bot.sh                          # потом вписать токен в /opt/mirofish/.env
sudo systemctl enable --now mirofish-bot
```

## Как пользоваться

Пришли боту текст или файл `.md`/`.txt`. Что именно проверить — первой строкой
через `?`, **по-английски** (промпты движка английские), материал может быть на русском:

```
?How will Almaty parents react to this price list?
<дальше сам оффер>
```

Команды: `/status` — очередь, `/runs` — последние прогоны, `/help` — формат.

Два раунда симуляции ≈ 10 минут. Больше раундов — дольше и точнее; крутится
в `MIROFISH_MAX_ROUNDS`.

## Чего здесь сознательно нет

- **Публичного доступа.** AGPL-3.0 обязывает раскрывать модификации при публичном
  сервисе, плюс любой прохожий жжёт лимиты подписки. Только белый список.
- **Ollama.** GPU нет ни на одной нашей площадке.
- **Больших прогонов без замера.** 1000 агентов не запускаем, пока не померен
  маленький прогон на этой машине.
